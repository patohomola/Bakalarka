\paragraph{subsubsubsection}{Príklad zarovnania}
Majme tri jednoduché sekvencie:
\begin{itemize}
    \item Sekvencia 1: \texttt{ACGT}
    \item Sekvencia 2: \texttt{AGT}
    \item Sekvencia 3: \texttt{ACCT}
\end{itemize}

Ich zarovnanie môže vyzerať nasledovne:

\begin{verbatim}
Seq1: A C G T
Seq2: A - G T
Seq3: A C C T
\end{verbatim}
